
# Language Models as Semantic Augmenters for Sequential Recommenders

This repository contains the code for the paper **"Language Models as Semantic Augmenters for Sequential Recommenders."**

## Recformer Fine-tuning
For Recformer fine-tuning, we use the official implementation provided by the authors:

https://github.com/AaronHeee/RecFormer/blob/main/finetune.py

## Augmented Semantic Signals
The augmented semantic signals generated by language models are available in the `Augmented_Signals` folder.
The **Art** and **Office** domains can be downloaded from the following link:

https://drive.google.com/drive/folders/1_wOdPFieL2hoChWenYSad4cMaaUUdF1G?usp=drive_link
